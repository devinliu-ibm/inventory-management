Factory Inventory Management System

Architecture overview: a Vue 3 single-page app over a FastAPI service backed by in-memory JSON data. No database.

System Architecture

Three tiers, two processes. The browser talks directly to the API over HTTP.

Frontend

Vue 3 SPA

Vite dev server, localhost:3000
Views: Dashboard, Inventory, Orders, Demand, Spending, Reports (Backlog is a view file, not routed)
Components: FilterBar, detail modals, ProfileMenu, LanguageSwitcher
Composables: useFilters, useAuth, useI18n
api.js: axios client
→HTTP / JSON
REST + query params
Backend

FastAPI service

uvicorn, localhost:8001 (docs at /docs)
Routes: /api/inventory, orders, demand, backlog, dashboard, spending, reports
Filtering: apply_filters, filter_by_month
Validation: Pydantic response models
CORS: all origins allowed

Data Flow

How a filter change on the dashboard becomes updated numbers on screen.

  1. User changes a filterTime period, warehouse, category, or order status in FilterBar. State lives in the shared useFilters composable.
  2. View reacts and calls the API clientA watcher in the view calls a method in client/src/api.js, which turns non-"all" filters into query params.
  3. axios sends the requestGET http://localhost:8001/api/...?warehouse=&category=&status=&month=
  4. FastAPI filters in memoryThe route runs apply_filters (warehouse, category, status) and filter_by_month (month or quarter, matched against order_date) on lists loaded from JSON at startup.
  5. Pydantic validates the responseList endpoints declare a response_model; the dashboard summary returns aggregates (inventory value, low-stock count, pending orders, backlog total).
  6. Vue updates the UIThe response lands in raw refs (for example allOrders, inventoryItems), and computed properties derive chart and table data, so the display re-renders.

Things to Know

  • All state is in memory and reloaded from JSON on restart; nothing is persisted.
  • client/src/api.js defines task and purchase-order calls (/tasks, /purchase-orders), but those routes are not defined in server/main.py. Only the PurchaseOrder models and the has_purchase_order flag on /api/backlog exist there.
  • The API base URL is hard-coded to http://localhost:8001/api in the client, and CORS allows all origins. Both are demo settings.
  • Inventory has no time dimension, so the month filter does not apply to it.
